#Radiology-mAs-Calculator
####Video Demo: https://youtu.be/BSwCw_PsJbY

####Description:

Radiology mAs Calculator is a simple educational web application designed to help
Radiology students understand and calculate mAs (milliampere-seconds) from two basic
exposure factors: mA (milliampere) and exposure time.

The idea behind this project came from combining two areas that are important to me:
programming and Radiology. Since I have a background in Radiology, I wanted to create
a programming project that was not just a general calculator, but something connected to a
field I already understand and care about.

The result is a simple calculator that demonstrates how a basic Radiology calculation can be
turned into an interactive web application.

##The Problem It Addresses:

In Radiology, students need to understand different technical factors used during X-ray
imaging. One of these concepts is the relationship between mA, exposure time, and mAs.

Although the calculation itself is simple, students who are learning Radiology may need to
practice it several times before the relationship becomes clear.

This project provides a simple way to practice that calculation. Instead of calculating the
result manually each time, the user can enter the mA and exposure time, press the
Calculate mAs button, and immediately see the result.

The project is mainly intended as a learning and practice tool, rather than as a
replacement for the calculations or controls available in modern X-ray systems.

##How It Works:

The calculator is based on a simple formula
mAs = mA × Time:
The user enters two values
● mA: the milliampere value.
● Time: the exposure time in seconds.
After entering the values, the user clicks the Calculate mAs button. The program takes the
two numbers, multiplies them together, and displays the calculated mAs on the screen.

##Educational Purpose:

The main purpose of the project is to connect a programming concept with a real example
from Radiology.
For someone learning programming, the project demonstrates how user input can be
collected, processed, and displayed as an output. At the same time, for a Radiology student,
it provides a familiar example that makes the programming concept easier to relate to .

The project therefore represents a connection between two different areas: programming
as the foundation and Radiology as the application.

It also demonstrates that programming does not always have to be used to create large or
complicated systems. Even a simple calculation can become a useful interactive application
when it is designed around a real-world need.

##User Interface

the application was designed with simplicity in mind. The user does not need to navigate
through multiple pages or complicated menus.

The main interface contains :

● An mA input field
● A time input field
● A calculation button
● A result area showing the calculated mAs.

The design uses a dark background with yellow accents to give the application a visual
connection to Radiology and medical technology. The interface is intentionally
straightforward so that the user can understand what to enter and where to find the result

##Tchnical Implementation:

The project was created using basic web development technologies.

HTML is used to create the structure of the application, including the input fields, labels,
button, and result area.

CSS is used to control the visual appearance of the calculator, including colors, spacing,
borders, typography, and the overall dark and yellow design.

JavaScript is responsible for the calculation and interaction. When the user clicks the
Calculate button, JavaScript reads the values entered in the mA and time fields, converts
them into numbers, multiplies them, and displays the result.

The project also uses Bootstrap to support parts of the interface and layout, as well as
Bootstrap Icons for the Radiology-related icon used in the application.

##Who Can Benefit From It?

The calculator is mainly intended for Radiology students and beginners who are learning
about exposure factors and want a simple way to practice the mAs calculation.

It can also be useful as a small demonstration project for programming students because it
shows how a real-world concept can be converted into a working web application.

The project is not intended to provide clinical recommendations or replace professional
Radiology equipment. Its purpose is educational: to demonstrate the calculation and the
connection between mA, time, and mAs.
